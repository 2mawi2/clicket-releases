# Clicket

Click anything from the keyboard. Builds for Apple silicon, macOS 13 or later.

Install or update with one line:

```bash
curl -fsSL https://github.com/2mawi2/clicket-releases/releases/latest/download/install.sh | bash
```

or with Homebrew:

```bash
brew install --cask 2mawi2/tap/clicket
```

Allow Accessibility once in System Settings > Privacy & Security > Accessibility.
Every release is signed with the same certificate, so the grant survives updates.
